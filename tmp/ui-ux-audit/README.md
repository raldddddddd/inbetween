# Inbetween UI/UX audit packet

Temporary task packet for the hackathon UI/UX pass. **Do not commit this folder as durable project documentation.** Extract this ZIP at the repository root so the files land under `tmp/ui-ux-audit/`, let Codex use it during the UI/UX pass, then delete it when the pass is complete.

Start with `codex_prompt.md`. The supplied screenshot is in `screenshots/`. `issues.md` captures the user-reported problems from all screenshots shown in the planning chat, including screenshots that were not available as separate files in the artifact runtime.

Primary design authority for this pass: Apple Human Interface Guidelines for macOS, popovers, charts, buttons, labels, and layout. See `references.md`.
